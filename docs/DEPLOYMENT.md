# Deployment guide

The deployment guide has been split into:

- [Installation](installation.md): release downloads, checksums, the installer
  and manual setup.
- [Operations](operations.md): systemd, reloads, certificates, updates and
  troubleshooting.
- [Configuration](configuration.md): the full YAML reference.

Start with [installation](installation.md) for a new server. The installer
starts an API-only service immediately; see its documented network exposure
before running it.
